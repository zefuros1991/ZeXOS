# Main keybinds

The keys you use every day. `Mod` is the Super (Windows) key. These do the same thing in both desktop shells and all three compositors.

## Open things

| Keys | What it does |
|---|---|
| `Mod+Space` | App launcher |
| `Mod+C` | Terminal (kitty) |
| `Mod+B` | Web browser (your default) |
| `Mod+E` | Files (Dolphin) |
| `Mod+M` | Install and update apps (Shelly on CachyOS, Discover elsewhere) |

## Wallpapers

| Keys | What it does |
|---|---|
| `Mod+W` | Wallpaper picker (roller) |
| `Mod+Shift+W` | Animated wallpaper picker |
| `Mod+Ctrl+W` | Random wallpaper |

## Move around

| Keys | What it does |
|---|---|
| `Mod+O` | Overview of every workspace (four fingers up on a touchpad) |

## Session

| Keys | What it does |
|---|---|
| `Mod+L` | Lock screen |
| `Mod+Escape` | Power menu |
| `Mod+Shift+D` | Change desktop shell (Noctalia or DankMaterialShell) |

## Help

| Keys | What it does |
|---|---|
| `Mod+F1` | Keybind cheat sheet |
| `Mod+Shift+Escape` | niri's hotkey overlay |

## Want the full list?

Every key lives in one file per compositor:

| Compositor | File |
|---|---|
| niri | `stow/niri/.config/niri/cfg/keybinds.kdl` |
| Mango | `stow/mango/.config/mango/cfg/keybinds.conf` |
| Hyprland | `stow/hyprland/.config/hypr/cfg/keybinds.lua` |

A few niri keys don't exist in Mango and Hyprland. See [Compositors and shells](compositors-and-shells.md).
